# AI-Офис — установка и запуск

Пиксельный офис, который показывает работу ассистента над вашим хранилищем: сотрудники читают заметки, печатают, выполняют команды. Всё, что вы видите, — настоящие события, а не анимация «для красоты».

## Главное про режимы Claude

Офис видит **Claude Code** — тот режим, где ассистент работает с папкой на вашем компьютере.

**Claude Cowork офис не видит, и это не чинится настройкой.** Cowork запускает ассистента внутри виртуальной машины: у неё своя файловая система, свои настройки и своя сеть. Папку хранилища она видит, поэтому заметки меняются, а вот сообщить офису о своих действиях не может — офис слушает ваш компьютер, а не виртуалку.

Для демонстраций и ежедневной работы с офисом запускайте **Claude Code в папке хранилища**.

## Установка (один раз)

1. Убедитесь, что установлен Node.js версии 20 или новее: [nodejs.org](https://nodejs.org), кнопка LTS.
2. Дважды кликните **`установить.command`** в этой папке.
3. Когда установщик попросит — перетащите в окно терминала папку своего хранилища Obsidian и нажмите Enter.

Установщик соберёт офис, сделает резервную копию настроек Claude и положит на рабочий стол ярлык **«Мой офис»**.

## Ежедневный запуск

1. Дважды кликните ярлык **«Мой офис»** на рабочем столе — откроется браузер с офисом.
2. Отдельно запустите Claude Code в папке хранилища и работайте как обычно.
3. Офис оживает, когда ассистент берётся за инструменты.

Закрыть офис — закрыть окно терминала, которое открыл ярлык.

## Что делает офис

| Действие ассистента        | Кто оживает      |
| -------------------------- | ---------------- |
| читает заметки             | Аналитик         |
| создаёт и правит заметки   | Секретарь        |
| ищет в интернете           | Ресёрчер         |
| выполняет команды          | Техник           |
| работает нанятый сотрудник | он сам, по имени |

Кнопка **«Сотрудники»** нанимает помощников: Юриста, Финансиста, Переговорщика, Кадровика, Маркетолога. Сотрудник создаётся **в вашем хранилище** — файлом в `.claude/agents/` и строкой в карте навыков. Он останется у вас, даже если офис удалить.

Кнопка **«Планировка»** — перестановка мебели и столов.

## Если офис пустой

- **Ассистент отвечает, но никто не шевелится.** Значит, он ответил, не открывая файлов. Персонажи реагируют на действия, а не на тему разговора.
- **Работаете в Cowork.** Офис его не видит — см. раздел выше.
- **Офис запущен не из папки хранилища.** Он следит за той папкой, из которой стартовал. Ярлык «Мой офис» подставляет её сам; если запускаете вручную — сначала перейдите в папку хранилища.
- **Выключены хуки.** Настройки → «Мгновенная реакция (хуки)».
- Как временное решение — Настройки → «Следить за всеми сессиями»: офис покажет любые сессии Claude Code, из какой бы папки они ни шли.

## Телеграм-бот: спрашивать с телефона

Бот принимает ваши сообщения в телеграме и запускает ассистента **на этом компьютере**, в папке хранилища. Ответ приходит обратно в телеграм, а офис в это время оживает — работает настоящий Claude Code, а не облако.

Заодно это обход ограничения Cowork: спрашивать можно с телефона, и при этом всё видно в офисе.

### Настройка

1. В телеграме напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите ключ бота.
2. Узнайте свой numeric id у [@userinfobot](https://t.me/userinfobot).
3. Создайте файл `~/.ai-office/telegram.json` по образцу `bot/telegram.example.json`:

```json
{
  "token": "ключ от BotFather",
  "allowedUserIds": [123456789],
  "vault": "/Users/имя/путь/к/хранилищу"
}
```

4. Убедитесь, что Claude Code авторизован: наберите `claude` в терминале и войдите. Без этого бот будет отвечать «не авторизован».
5. Запустите бота: `node bot/telegram-bot.mjs`

### Команды

`/start` — подсказка с примерами · `/новый` — начать разговор заново. Всё остальное уходит ассистенту как обычный вопрос: «Утренний бриф», «Подготовь к встрече с Ивановым», «лог: созвонился с поставщиком».

### Что важно понимать про безопасность

У бота **полные права** на этом компьютере — он может не только читать и писать заметки, но и выполнять команды. Поэтому:

- **`allowedUserIds` обязателен.** С пустым списком бот не запустится: иначе любой, кто найдёт бота, получит доступ к вашей машине.
- **Ключ бота — это пароль.** Файл `~/.ai-office/telegram.json` не пересылайте и не кладите в облачные папки.
- Если ключ утёк — отзовите его у @BotFather (`/revoke`) и получите новый.
- Компьютер должен быть включён и не спать, иначе бот не ответит.

## Безопасность

Офис работает только на вашем компьютере, наружу ничего не отправляет. Он подключается к Claude через файл настроек `~/.claude/settings.json` — установщик делает его резервную копию перед первым запуском. Отключить связь можно тумблером «Мгновенная реакция (хуки)» в настройках офиса.
