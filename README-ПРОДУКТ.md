# AI-Офис и телеграм-бот

Часть продукта «второй мозг для бизнесмена»: пиксельный офис, показывающий работу
Claude Code вживую, и телеграм-бот, дающий доступ к хранилищу с телефона.

Это форк [pixel-agents](https://github.com/pixel-agents-hq/pixel-agents) (MIT)
с дописанным слоем ролей, наймом ИИ-агентов, русификацией и ботом.

## С чего начать

**Весь контекст проекта — в `HANDOFF.md` репозитория с хранилищами.** Там
объяснено, что построено, почему именно так, и на какие грабли уже наступили.
Читать до первого действия.

## Быстрый старт

```bash
npm install && npm run build
cd /путь/к/хранилищу && node /путь/к/ai-office/dist/cli.js --port 4317
```

**Запускать обязательно из папки хранилища** — офис следит за той папкой, из
которой стартовал. Ярлык, который создаёт `установить.command`, делает это сам.

Бот: `node bot/telegram-bot.mjs` (нужен `~/.ai-office/telegram.json`, образец —
`bot/telegram.example.json`).

## Скрипты для продавца

- `установить.command` — установка под ключ двойным кликом
- `сбросить-демо.command` — возврат демо к эталону перед показом клиенту

## Важное

- Офис видит **Claude Code**. Режим **Cowork не видит** — тот работает в
  виртуальной машине. Подробности в `HANDOFF.md`.
- У спрайтов персонажей из апстрима нет формальной лицензии. Для продажи нужно
  купить LimeZu Modern Interiors и подключить через Settings → Add Asset Directory.
  Купленные ассеты в публичный репозиторий не класть.
- Секреты (`~/.ai-office/telegram.json`) лежат вне репозитория. Проверяйте перед
  публикацией: `grep -rn "AAH" .` не должен находить ключей.
